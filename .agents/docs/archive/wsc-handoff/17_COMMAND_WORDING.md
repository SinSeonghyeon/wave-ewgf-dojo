# 입력 용어를 커맨드로 통일 — 2026-09-18

사용자 요청에 따라 영상에서 입력을 가리키던 “순서”를 “커맨드”로 통일했다. 제작 절차나 촬영 순서를 설명하는 내부 문서의 일반 용례는 유지한다.

- 본편 비교 내레이션·자막: “커맨드를 따라 했어도, 타이밍이 어긋나면 실패합니다.”
- 쇼츠 첫 내레이션·자막: “웨캔기어. 커맨드는 맞는데, 왜 풍신권이 나올까요?”
- 화면: 커맨드는 간단합니다 / 같은 커맨드, 다른 결과 / 커맨드와 두 번의 타이밍 / 같은 커맨드인데 / 커맨드 다음은.
- 썸네일·미리보기·제목·설명란·영어/일본어 번역 전 템플릿도 같은 용어로 갱신한다.

제작 폴더는 `.sandbox/wsc-workspace03-production/`. 변경된 음성 두 개를 재생성하고 `render_command_wording.py`로 화면 6개(topic, simple, fail_compare, search, s_hook, s_command)를 다시 그린다. 나머지는 직전 승인본의 clean 장면을 재사용한다. 백업은 `cache/before-command-wording/`. 전체 재생성은 `build.py --all`이다. 영상과 소스 ZIP은 Git 제외 상태를 유지한다.

검토: `preview.html`의 본편 방법 소개(0:31), 커맨드 설명(0:59), 실패 비교(1:18)와 쇼츠 첫 멘트를 소리 켜고 확인한다. 본편 5:02.13, 쇼츠 0:55.05. 앱 변경·커밋·푸시 없음.
