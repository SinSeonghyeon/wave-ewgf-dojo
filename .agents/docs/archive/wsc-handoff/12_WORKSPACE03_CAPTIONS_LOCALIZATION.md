# workspace03 — 문장 자막·프레임표·다국어 확장

2026-09-18 · bbbb201 기반 후속 수정. 직전 영상·소스는 `.sandbox/wsc-workspace03-production/cache/before-caption-frame-revision/`에 보존했다.

## 반영 내용

1. 영상의 제목·큰 화면 문구에서 온점을 제거. 내레이션과 문장 자막의 문장 부호, 소수점, 출처의 Inc.는 유지한다.
2. 16분할 몽타주 말미를 “직접 기록하고 분석했습니다”로 수정.
3. 실제 입력 이력 클로즈업이 왼쪽에서 확대되며 화면 중앙으로 이동하도록 변경. 배경은 블러·딤 처리, 노란 테두리로 시선 유도.
4. 7f 기준 이후 1칸, 8f 이후 2칸, 9f 이후 3칸의 허용 구간 다음부터 표시된 모든 칸을 붉은 X로 채운다. 축을 15+까지 늘리고 “허용 구간 이후는 모두 실패”를 명시한다. X는 글꼴 기호 대신 두 선으로 칸 중심에 그린다.
5. 본편·쇼츠 음성과 자막을 “1/2/3프레임까지 허용합니다”로 통일. RP는 허용 칸에서 한 번 누르는 규칙 유지.
6. 후반 ↙ 실수 시 횡이동 설명 제거. ↓를 짧게 눌렀을 때의 기존 관찰은 별개 내용이라 유지.
7. 214를 가장 추천하는 이유를 제작팀 기준 “난이도가 가장 쉽고 실수가 적었기 때문”으로 변경. 추가 촬영에서 ↙ 실패 사례 요청 제거.
8. 문장 단위 SRT, 하단 자막 비삽입 clean MP4, 장면 ID/더빙 슬롯, 분리된 음성·배경음·효과음, en/ja 번역 템플릿과 화면 문구 사전 마련. `localize.py`로 자막 출력과 더빙 조립 가능. 화면 한국어까지 유튜브가 번역하는 것은 아니며 별도 번역 렌더에는 레이아웃·일본어 폰트 검수가 필요하다.
9. 자막을 27글자마다 잘라 교체하던 방식에서 문장 단위로 변경. TTS 단어 시각으로 문장 시작을 맞추고 긴 문장은 본편 최대 두 줄, 쇼츠 최대 세 줄로 배치. 중간 구절이 사라졌다가 다음 구절이 나오는 문제 제거.

## 파일과 확인

현재 납품은 제작 폴더 `preview.html`. 본편 282.6초, 쇼츠 50.433초. 기본 MP4는 자막 포함 검토본, `*-clean-*.mp4`는 유튜브 언어별 자막용이다. 실제 영어·일본어 번역/더빙 완료본은 아니다. 상세 방법은 `LOCALIZATION.md`.

미리보기의 “프레임표 중앙 이동”, “허용 구간 이후 실패”, “2프레임까지 허용”, “3프레임까지 허용”, “제작팀 추천”을 확인한다. 문장 단위 자막과 음성의 자연스러움은 직접 재생해 확인한다. 추가 촬영 표시와 준비값 실측 대조 대기는 유지한다.

유튜브 공식 안내(2026-09-18 확인): https://support.google.com/youtube/answer/2734796?hl=en , https://support.google.com/youtube/answer/13338784?hl=en-VC , https://support.google.com/youtube/answer/6289575?hl=en . 자막·번역 제목/설명, 고급 기능 접근 권한이 있는 제작자의 다국어 오디오, 본편 언어별 썸네일을 지원한다. 채널 접근이나 게시 작업은 하지 않았다.
