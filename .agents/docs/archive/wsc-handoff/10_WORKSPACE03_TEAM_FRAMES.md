최신 사용자 요청 7개와 추가 네모 입·프로필 요청을 함께 반영한다. `.sandbox/wsc-workspace03-production/preview.html`이 현재 미리보기다. 이번 출력에는 사용자가 요청한 **촬영본 교체 예정 표시**가 있으므로 공개 업로드 완료본으로 부르지 않는다. 이전 영상·소스는 `cache/before-team-frame-revision/`에 보존했다.

## 변경

- 철권 8 공식 사이트의 소개 영상에서 역재생·잔상·필름 이동·연도 카운터로 시간을 감은 뒤 실제 태그 1 PS2 영상으로 연결. 카운터의 중간 연도는 연출이며 각 연도 작품을 보여준다는 뜻이 아니다. 공식 원본: https://en.bandainamcoent.eu/tekken/tekken-8 의 `TEKKEN8-KF01.webm`, `TEKKEN8-KF02.webm`. 외부 영상 음원은 쓰지 않는다. 별도 CC 라이선스나 게임사 개별 허락을 받았다고 주장하지 않는다.
- 28.4초 주제 소개에서 기존 실패 후보 영상을 제거. 왼쪽은 입력 순서/타이밍 도식, 오른쪽은 공식 게임플레이 자료로 “방법과 활용”을 소개한다. 공식 자료를 웨캔기어 시연이라고 표시하지 않는다.
- 프레임 원이 다음 입력 칸에 가려지던 그리기 순서를 수정. 모든 칸을 그린 후 7·8·9 숫자를 원으로 둘러싼다. 타원 대신 실제 원을 직접 그리며, 쇼츠의 원도 같은 함수를 사용한다.
- 내레이션·자막·화면의 방향 지칭을 “뒤 입력”으로 명시. “제가/제 테스트/제 체감/개인 테스트”는 “제작팀” 표현으로 변경. 시간 순서의 “그 뒤”는 “이후”로 정리.
- 영상 속 캐릭터의 몸·머리는 그대로 유지하고 말하기 입만 타원에서 네모로 변경. 음성 평활화와 고정 몸 방식 유지.

## 새로 제공된 수치

이 요청은 이전의 “수치 비교 없이” 결정을 대체한다. 아래 값은 **사용자가 제공한 최대 속도 기준, 공격 버튼 입력 전 최소 준비 시간**이며 에이전트 독립 실측이 아니다.

| 방법 | 최소 준비 시간 |
|---|---:|
| 웨캔기어 | 8f |
| 아래 유지 | 8f |
| 뒤로 굴리기 — ↓ ↙ ← / 214 | 7f |
| 대각선 아래 뒤 — ↙ | 7f |

기술 자체 발동과 타격까지의 시간은 제외한다. `data.json` 및 제작 폴더 `source-data.json`의 `comparison.rows[].preparation_f`에 기록했고, `input_to_hit_f`는 null을 유지했다. 근거는 `user_report_explicit_pending_capture`다. 후속 답변으로 웨캔기어 8f는 ↘ 입력부터로 확인되었다. 앞선 → ★ ↓ 시간은 제외한다. 촬영 대조는 남아 있다. 최신 편집·검증은 `11_WORKSPACE03_PAUSE_FLOW.md` 참조.

제공 최소값에서는 두 7f 방법이 짧다는 설명, ↙ 입력 실수 시 횡이동 위험을 고려한 제작팀의 214 추천, 웨캔기어는 웨이브 중 이어져 부드럽게 느껴졌다는 주관적 조작감을 별도 문장·장면으로 나눴다. 조작감을 속도 우위로 바꾸지 않는다.

## 추가 촬영

필수 5종: 웨캔기어 8f 성공, ↓ 유지 8f 성공, 214 7f 성공, ↙ 7f 성공, ↙ 입력 실수로 실제 횡이동이 나오는 사례. 성공은 각 2~3회, 실패는 1~2회면 된다. 선택 1종: 웨이브 접근 중 기상어퍼를 활용하는 대전/훈련장 장면.

공통: 같은 캐릭터·방향·가능하면 같은 거리/상태, 입력 이력과 유지 프레임 표시, 1080p·60fps 게임 원속도, 시도 전후 2초 포함. 각 방법에서 어느 입력부터 RP 직전까지 셌는지 알려준다. 상세 촬영표는 제작 폴더 `SHOOTING_GUIDE.md`, 교체 장면 시간표는 `replacement-slots.json`이다.
