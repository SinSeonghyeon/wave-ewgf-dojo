## 시안은 주지 않는다

- 기존 미리보기 HTML, 모션 코드, 렌더 MP4, 스크린샷, 기존 캐릭터 재작화는 넘기지 않는다.
- 기존 `.sandbox/wsc-video/`와 과거 설계 로그를 연출 참고용으로 탐색하지 않는다. 해당 파일들은 최신 결정과 다른 내용을 포함한다.
- 전달할 것은 이 문서 묶음, 원본 캐릭터 이미지, 원본 실험 메모, 원본 플레이 촬영본뿐이다.
- 같은 저장소에서는 상위 `AGENTS.md`의 안전 규칙을 준수한다. 다만 앱의 공식 캐릭터 금지/단일 HTML/i18n 제약을 별도 영상 제작물에 기계적으로 적용하지 않는다. 앱 파일은 수정하지 않는다.
- 이전 자료와 충돌하면 이 패키지의 최신 결정이 우선이다. 추가 사용자 피드백은 이 패키지보다 우선한다.
