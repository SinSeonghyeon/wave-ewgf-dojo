## 변경

1. **몽타주 프레임**: 이전에는 1.35초/41프레임 클립을 2.3~5.9초 장면 길이에 비례해 인덱싱해 같은 프레임을 반복했다. 파일 자체는 30fps였지만 동작이 약 7~18fps처럼 보이는 구간이 있었다. 출력 프레임마다 원본 30fps 캐시의 한 프레임씩 진행하도록 수정했다. 분할 전환에서도 재생 시점을 누적해 기존 타일이 처음으로 돌아가지 않는다. 짧은 시도는 원속도로 반복하며 화면에 반복 재생이라고 표시한다. 최초 큰 타일의 원본 해상도도 올렸다. 실제 서로 다른 시도 16개라는 근거는 유지한다.
2. **소개 배경**: 무료 Pexels의 게임 컨트롤러 조작 영상으로 교체. 소개 배경은 입력 실험 증거가 아닌 분위기용 자료 화면이다.
3. **이름 조합**: 웨이브·캔슬·기상·어퍼의 첫 글자를 강조한 뒤 나머지 글자가 사라지고, 첫 글자가 곡선 경로를 따라 모여 웨캔기어가 된다.
4. **태그 대사·자료**: 원래 지정한 “그런데, 이 테크닉은 어쩌다 등장하게 됐을까요? 그 이야기를 하려면, 철권 태그 시절로 돌아가야 합니다.”와 “하지만 오늘은 여기까지 다루지는 않겠습니다.” 복원. 단일 철권 8 장면을 거꾸로 돌리던 연출을 제거하고, 현재 화면에서 실제 태그 1 PS2 자료 영상으로 전환한 뒤 끝낸다. 해당 자료는 작품 식별용 오프닝 발췌이며 기술의 기원을 독립 입증하는 자료라고 주장하지 않는다.
5. **캐릭터 떨림**: 음성의 35ms 크기 변화에 따라 서로 다른 전신 그림을 바꾸던 것이 원인. 전신·머리 그림을 하나로 고정하고, 평활화한 음성 세기로 입 부분만 움직인다. 음성 연동 회전·스케일 변동을 제거하고 완만한 등장/퇴장과 작은 호흡만 남겼다.
6. **손 조작·기호**: 별도의 무료 컨트롤러 손 클로즈업 사용. 기존의 어색한 선 모양을 `≠` 도형으로 명확히 교체. 방향·중립·부등호는 직접 그리며, 텍스트 내 사용 기호도 폰트의 누락 글리프와 다른지 검사했다.
7. **커맨드 간격**: 웨이브 4입력 / 뒤 / RP 세 묶음. 충분한 여백, 단계 이름, 곡선 점선과 손그림 연결선으로 순서를 구분했다.
8. **실패 비교 전환**: 선 자세 영상이 축소되는 동안 이전 풍신권 영상을 아래 레이어에 계속 유지한다. 전체화면 B에서 비교 화면으로 넘어갈 때 A가 다시 사라졌다 나타나는 공백을 제거했다.
9. **자료 탐색 장면**: 실제 커뮤니티 캡처처럼 꾸미지 않고, 자료를 보며 생긴 질문을 직접 만든 종이 메모 3장으로 재구성했다. “내용 재구성”을 표시했다. 사용자 실패 모음은 몽타주에서 보여준다.
10. **입력 설명 디자인**: 따뜻한 종이 키캡, 미세한 점 배경, 테이프 메모, 손으로 그은 밑줄·괄호·강조선. 기존 프레임 수치와 7→8→9, RP 1/1–2/1–3 조건은 그대로 유지한다.

## 재생성과 확인

현재 구현은 `build.py`가 `refinement.py`를 적용한다. `make_voice.py` → `build.py --main` / `--short` → `delivery.py` → `verify.py`, `verify_revision.py`, `qa-browser.cjs` → `pack_source.py` 순서다. 필요한 외부 발췌 파일 3개와 출처 JSON은 편집 소스 ZIP에 포함한다.

미리보기의 첫 글자 합치기, 철권 태그 자료, 손 조작·캐릭터, 커맨드 새 디자인, 실패 비교 전환, 자료 탐색 메모, 몽타주 전환, 프레임 설명 버튼으로 각 변경을 확인한다. 직접 음성을 청취한 검증은 하지 못했다. 사용자에게 소리 켜고 확인하도록 안내한다.

## 최종 검증

- 본편 238.167초 / 7,145프레임, 쇼츠 45.767초 / 1,373프레임, 모두 1080p·30fps·H.264/AAC. 전체 디코딩 오류 없음.
- 자막 총 85구간: 시간 역전·겹침·장면 범위 초과 없음.
- 몽타주 소스 시계: 5종 분할 모두 출력당 원본 한 프레임 진행, 전환 시 연속성 통과.
- 실제 인코딩 MP4의 같은 몽타주 1초 비교(평균 픽셀차 0.30 이하를 거의 반복된 프레임으로 분류): 이전 30쌍 중 17쌍, 수정 후 0쌍. 원본에서 진행되는 30쌍 전부 동작 변화 확인.
- 브라우저: 각 영상 5개 지점 탐색·실제 재생, 구간 바로가기 8개 통과, 최종 JS 오류 0. 몽타주 6초 재생 180프레임 / 드롭 0.
- 최초 바로가기 자동검사에서 빠른 pause가 아직 시작되지 않은 play 요청을 중단해 AbortError 3건 발생. 미리보기에서 중단된 재생 요청을 처리하고, 검사도 탐색 완료 후 재생을 확인하도록 수정한 뒤 재통과.
- 캐릭터 말하기 단계 간 변경은 입 주변 33×17픽셀 내로 제한되고 몸·머리 외형은 동일함을 검사. A/B 축소 전환 4개 지점에서 A가 계속 존재함을 확인.
- 특수기호 10종 폰트 누락 없음. 부등호와 주요 입력 기호는 직접 도형으로 그림. 최종 MP4에서 주요 장면 8개 추출 육안 확인.
- 본편 최종 음량 -16.22 LUFS / -4.43 dBTP. 직접 청취 검증은 미실시.
- 앱은 바꾸지 않았으므로 앱 단위/스모크는 재실행하지 않았고, 영상·미리보기 검증을 수행했다. 원본 영상·외부 공유 ZIP은 수정하지 않았다.
- 실행 결과: `qa/verification.json`, `qa/revision-regressions.json`, `qa/encoded-cadence.json`, `qa/symbol-check.json`, `qa/browser.json`.
