- 이 폴더는 gitignore 대상. 미디어/소스를 보관할 때 폴더 전체를 함께 복사한다. 원본 플레이는 data.json의 외부 경로로 읽는다.

## 연출과 범위

실제 플레이를 중심으로 입력 칸을 이어 붙인다. 어두운 청록 바탕, 뒤 입력 황색, RP 청록. 실패 A와 B를 각각 전체 화면으로 보여주고 비교 위치로 축소한다. 원본 캐릭터는 새 도형 코드로 단순하게 재작화했으며 내레이터 역할만 한다. 말하는 입은 임시 리듬이다.

첫 샘플은 핵심 연결을 40초 이내로 보여주는 발췌본이다. 역사 되감기·주제와 자신감 대사는 장면표에 유지하되 이번 샘플에서는 생략했다. 본편과 쇼츠를 완료한 것으로 취급하지 않는다. 16분할 몽타주와 실전/대안 비교는 다음 범위다.

원본 성공과 실패의 연속 프레임을 추출해 외형을 확인했다. 입력 로그 후보는 특정 A+B의 증거로 확정하지 않았다. 커맨드는 설명용 순서이며 실제 입력과 동기화한 분석 결과가 아니다. 게임 소리는 음악/효과음이 섞여 있어 샘플에서 제외했다.

## 검증과 미확인

- MP4 두 파일 전체 FFmpeg 디코딩 오류 없음.
- Chrome에서 각 파일 시작·중간·끝 seek 및 재생 성공, 1280×720, 오류 0.
- 대표 장면 육안 확인, SRT·타임라인 별도 저장, PCM 최대 진폭 intro 0.755 / frames 0.611, 최대치 클리핑 없음.
- TTS 직접 청취는 하지 못했다. 발음·자연스러움은 사용자 확인 필요.
- 단위 테스트 97개 통과. 앱 브라우저 스모크 통과, errors: [] (`app-smoke.txt`).
- 첫 프레임 포함 규칙, 9+2 개별 촬영, 비교 4행 실측, 실전 예시, 중복 없는 실패 16개, 역사 주장, 캐릭터 공개 권리 확인이 남았다. 인계 데이터 null/dummy를 바꾸지 않았다. 최종 공개본이 아니다.

## 직접 볼 항목

preview.html에서 두 영상을 재생해 도입 호흡, 캐릭터 모양·비중, 실패 화면 축소 전환, 프레임 칸의 글자 크기·RP 강조 속도, 임시 TTS 발음을 확인한다. 밝은 RP 칸은 그중 한 번을 누르는 선택 가능한 칸이며 연속 누르기 지시가 아니다.
