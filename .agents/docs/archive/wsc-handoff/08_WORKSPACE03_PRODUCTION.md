## 제작

1080p 원본 플레이 중심, 새 Pretendard 타이포그래피, 입력 순차 강조와 프레임축, A/B 전체 화면→축소 비교, 실제 서로 다른 시도 1→2→4→8→16 몽타주. 원본 입력 기록 확대에서 두 간격 설명으로 연결. 후반은 활용 선택지→어려운 캔슬이 필요한가→세 대안→4행 입력 비교→개인에게 맞는 선택 순서다. 7→8→9 / RP 1·1–2·1–3f 유지, 8+1 연습 추천 없음. 쇼츠는 별도 세로 배치.

무료 Edge 신경망 한국어 남성 음성(ko-KR-InJoonNeural), 단어별 타이밍 기반 자막, 불필요한 문장 말미 무음 제거. 자체 합성한 배경음·효과음과 대사 중 음악 볼륨 감소. 원본의 혼합 게임 음악/효과음은 사용하지 않음. 외부 유료 서비스·API 결제 없음.

## 사실·권리 처리

최초 출력에서는 비동기 질문 답변 전이라 캐릭터를 제외했다. 이후 사용자가 “추가 소재 없음 — 수치 비교 없이 제작”, “공개 사용 가능”을 명시적으로 확인했다. 전체 소요 시간 수치는 만들지 않고 입력 방법·선택 기준과 개인 관찰 범위를 유지했다. imagegen으로 준비한 내레이터 소재를 본편 다섯 구간(도입 농담, 아는 것/손으로 하는 것, 대안 입력 세 구간)에 합성했다. 캐릭터는 짧은 내레이션 전달자이며, 쇼츠·썸네일에는 등장하지 않는다. 최신 모션판에서는 고정된 밝은 바탕을 없애고 캐릭터 선을 따라가는 외곽선·그림자로 합성했다. 이전 출력은 cache에 보존했다.

미확정 역사 기원 대사는 구체적 기원 주장 없는 되감기 개그로 수정했다. 실전 촬영이 없는 훈련장 장면은 연습 모드 동작 예시로 표기했다. 실패 클립에 특정 A+B 원인을 붙이지 않았다. 9+2 개별 메모 행과 첫 프레임 포함 규칙의 영상 대조는 여전히 미완료이며, 사용자가 확인한 규칙과 독립 검증을 구별한다. 인계 데이터의 null/근거 수준은 보존했다.

## 검증

- 최종 MP4 전체 디코딩 오류 없음: 본편 6,989프레임, 쇼츠 1,373프레임.
- 브라우저: 각 영상 5개 지점 탐색, 실제 재생 시간 증가, JS 오류 0.
- 자막 총 83구간: 장면 범위 내, 시간 역전·겹침 없음.
- 최신 모션판 전체 재렌더 후 최종 인코딩 영상에서 캐릭터 등장 연속 프레임·가리키기·몽타주 전환·배경 블러와 입력 칸을 추출해 육안 확인. 쇼츠 안전영역 확인.
- FFmpeg 음량 측정: 본편 -16.24 LUFS / -4.44 dBTP, 쇼츠 -15.97 LUFS / -4.49 dBTP. 클리핑 없음.
- 원본 플레이 SHA256 `8c1bccdbca3e045b885d6f1ca0ab4da07031ae5be3730e64726bc5517427276e`로 이전 작업 해시와 일치.
- TTS의 자연스러움은 직접 청취 검증하지 못했다. 게시 전 사용자 재생 확인이 필요하다. 게임 실험을 에이전트가 직접 수행했다고 주장하지 않는다.
- 앱 변경 없음. 앞선 샘플 작업의 단위 테스트 97개/앱 스모크 통과 이후 앱은 건드리지 않았으며, 이번에는 영상 검증을 실행했다.

## 후속 모션 개선 (2026-09-17)

사용자의 정적인 내레이션 구간 개선 요청을 반영했다. 캐릭터의 탄성 있는 등장·퇴장, 음성 세기에 맞춘 말하기/쉼 포즈, 몸 기울임·끄덕임, 입력 가리키기를 추가했다. 배경 플레이에는 가변 블러를 적용하고 글자·자막·입력 칸은 선명하게 유지했다. 몽타주는 축소·이동하며 분할 수가 늘어나고, 대안 입력에는 방향 다이얼, 프레임 설명에는 그려지는 원과 RP 연결선을 추가했다. 등장·전환 합성 효과음도 추가했다. 쇼츠에는 포커스 전환·입력 칸 등장 모션을 적용했다. 새 외부 스톡 소재 없이 원본 촬영과 직접 만든 모션으로 구성했다.
