# 벡터 타이밍 창·숫자 방향 표기 — 2026-09-18

사용자 요청으로 카툰 시험은 채택하지 않고, 벡터 타이밍 창을 제작해 본편 프레임 설명에 반영했다. 10초 별도 테스트는 `.sandbox/wsc-workspace03-production/exports/vector-timing-test.mp4`다.

## 용어·번호

- 첫 멘트: “여러분은, 웨캔기어라는 기술을 들어보셨습니까?”로 음성·자막 변경.
- 214 명칭은 **뒤 웨이브**. 방향 표현은 숫자로: 6=→, 4=←, 2=↓, 3=↘, 1=↙. 중립은 N.
- 1P 기준이며 처음 6N23 소개에 키패드 대응표를 보여준다. 직접 그린 화살표 위에 작은 숫자, 중립 별 위에 N을 붙인다. 게임 원본에 포함된 입력 이력은 수정하지 않는다.
- 화살표 위 숫자는 방향, 칸 아래 숫자는 프레임째. 두 입력 타이밍 도입에서 차이를 명시한다.
- 3 입력이 1프레임째, 4 입력 시점은 8·9·10프레임째. RP 절대 위치는 각각 9 / 10·11 / 11·12·13. 뒤 웨이브 최속6f를 포함한 비교 8·8·6·7과 기존 경과 간격 메모는 보존한다.

## 연출

반복 게임 인셋을 쓰던 간격/허용 구간/개별 타이밍/요약을 자체 도형으로 교체. 노란 이동점이 4 입력 시점에 도착하면 초록 RP 허용 창이 표시되고, 성공 시 체크 표시, 늦은 입력은 빨간 점과 X로 표시한다. 프레임 숫자의 원과 모든 초과 칸의 중앙 X를 유지했다. 게임의 실제 프레임 속도가 아닌 설명용 확대라는 문구를 넣었다.

`vector_revision.py`가 기존 렌더 마지막에 설치되어 숫자 표기·화살표 윗숫자·키패드·벡터 장면을 그린다. 신규 생성 이미지·외부 영상 없이 로컬 도형만 사용했다. 쇼츠도 음성·자막·방향 윗숫자·명칭 변경을 반영한다. `render_numeric_vector.py`는 로컬 직전 clean 출력에서 변경 없는 장면만 재사용하는 증분 렌더 도구이며, 전체 재생성은 여전히 `build.py --all`이다. 직전 출력은 `cache/before-vector-numeric/`에 보존했다.
