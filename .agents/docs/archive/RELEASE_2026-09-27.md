## en

Title: 623 input and gamepad settings update

Summary: Added support for inputs without neutral, gamepad bindings and input checking.

1. Following in-game verification, 623 is accepted as a wave prefix alongside 6N23, including for standard EWGF, Hellsweep and WSC. This corrects the September 21 neutral requirement. Cancel forward and the next starting forward remain separate.
2. Fixed WSC challenge wave counts falling out of sync with consecutive waves when releasing diagonal to down before linking the next wave.
3. Edit keyboard and gamepad bindings at the top of Settings. Assign primary and alternate gamepad inputs for each action, clear individual gamepad slots, or restore defaults.
4. Turn on Test inputs to highlight matching bindings. Fresh input switches to the matching keyboard or gamepad tab.
5. Bindings are saved in this browser and shared across gamepads. Release your inputs after closing Settings before resuming practice.

## ja

タイトル: 623入力とパッド設定の更新

概要: 中立省略入力に対応し、パッドの割り当て設定と入力確認を追加しました。

1. ゲーム内での確認を反映し、623も6N23と同じウェーブの先行入力として認めます。通常の最風・奈落・WSCにも適用され、9月21日の中立必須の案内を訂正します。キャンセルの6と次の開始6は引き続き区別します。
2. WSCで斜め入力から下入力に戻して次のウェーブにつなぐと、チャレンジのウェーブ数が実際の連続入力とずれる問題を修正しました。
3. 設定画面の上部でキーボード・パッドの割り当てを変更できます。パッドも各操作にメイン・サブ入力を設定し、個別解除や初期設定への復元ができます。
4. 入力確認をオンにすると、押した入力に対応する欄が光ります。新しく入力したデバイスに合わせてキーボード・パッドのタブが自動で切り替わります。
5. 割り当てはこのブラウザーに保存され、すべてのパッドに共通で適用されます。設定を閉じた後は一度入力を離してから練習を再開してください。
