## 남은 검증 범위와 유지보수 참고

- 실제 키보드·게임패드의 지연, 비표준 DirectInput 장치별 hat 매핑, 모든 화면 폭의 시각적 품질은 이번 자동 검증에 포함되지 않는다.
- 캔버스 입자·더미 물리는 프레임마다 고정량으로 갱신하므로 모니터 주사율에 따라 연출 속도가 달라질 수 있다. 입력 판정은 시각 기반이며, 연출의 시간 기반 갱신은 별도 개선 대상이다.
- 테스트의 DOM 모사는 판정 회귀 확인용이다. 브라우저 이벤트 순서와 실제 키 리맵 조작을 모두 대체하지는 않는다.
- 단일 파일 내 상태 머신과 DOM 갱신이 직접 연결되어 있다. 공통 초기화와 독립 회귀 테스트로 현재 위험을 줄였으며, 기능 확대 시 판정 결과를 반환하는 순수 로직과 화면 표시를 분리하면 테스트와 변경이 쉬워진다.
