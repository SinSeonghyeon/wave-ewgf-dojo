# 내부 보관용 — 공개 대사/자막/설명란 자동 삽입 금지

- 프레임 조건을 다룬 Reddit 댓글 스레드: https://www.reddit.com/r/Tekken/comments/xahati/mishima_cd_to_iws_cancel_technique/

둘 다 철권 7 시절 자료로 분류해 보관해온 선행 자료다. 사용자가 철권 8에서 독립적으로 테스트한 후 확인 과정에서 발견했다. 이번 인계 패키지를 만들며 링크 내용이나 영상 자체를 새로 확인한 것은 아니다. '레퍼런스 영상을 직접 보고 연출 분석했다'고 주장하지 않는다.

사용자는 참고 자료를 내부 설계에만 남기길 원한다. 이 패키지는 레퍼런스의 편집 스타일이나 영상 클립을 가져오라는 요청이 아니다. 외부 자료가 필요해 실제로 열람할 경우 확인된 사실과 추정을 구분한다. 타인의 자료를 직접 사용하려면 권리와 표기 문제를 별도 확인한다.

철권 태그 시절 기원 대사의 증거로 이 두 링크를 자동 이용하지 않는다. 역사 확인은 별도 필요하다.
