# 제작 브리프 — 고정할 내용과 자유롭게 만들 부분

## 목적 / 시청자 / 결과물

- 한국어 유튜브. 기술을 처음 접하는 철권 플레이어도 목표 동작을 먼저 이해할 수 있어야 한다.
- 철권 8, 데빌진, 기상 RP. 메모의 왼손/LP 표현은 사용자 정정에 따라 RP로 취급.
- 본편은 사용법 + 프레임 조건 + 다른 입력과 비교 + 결론. 쇼츠도 원래 요청 범위이며 본편을 확정한 후 핵심을 재구성한다.
- 본편 16:9 / 쇼츠 9:16. 길이·해상도·출력 fps·폰트·색상·도구는 확정되지 않음. 권장 출발점은 1080p, 길이는 읽기 테스트 후 정한다. 과거 시안의 러닝타임에 맞추지 않는다.
- 한국어 TTS, 자막, 실제 플레이, 애니메이션을 결합. 사용 가능한 임시 음성이 곧 최종 승인 음성은 아니다.
- 편집 가능한 소스, 데이터 분리, 음성/자막 교체 가능 구조를 함께 납품. 다국어 확장을 위해 자막 원본(SRT 등)과 내레이션 텍스트를 보존하되 자동 번역/다국어 더빙 제작은 이번 필수 범위가 아니다.

## 톤과 캐릭터

- 살짝 진지한 다큐멘터리를 패러디. 담담한 목소리와 화면의 대비, 짧은 정적으로 웃음을 만든다. 과장된 예능/밈 난사 아님.
- 깔끔하고 손으로 만든 듯한 선·밑줄·강조를 활용. 디자인 템플릿/교육용 PPT 느낌 금지.
- 사용자 지정 이미지 아래 오른쪽 수염 캐릭터 사용. 비대칭 눈과 눈썹, 짧은 뾰족 머리, 네모 수염, 검은 빗금 몸통의 단순한 드로잉이다.
- 캐릭터는 내레이션 전달자. 말에 맞춘 작은 표정/입/몸짓, 가벼운 가리키기 정도. 상시 등장 필수 아님.
- 연구원 설정, 기록지를 들고 실험하는 역할극, 실패의 주인공, 길어진 팔로 프레임을 밀기 등 과거 캐릭터 연출은 폐기. 캐릭터가 아니라 플레이·입력 기록이 주인공이다.
- 원본 누끼 또는 충실한 벡터 재작화는 제작자가 선택할 수 있으나 어떤 방식을 썼는지 명시. 기존 시안의 캐릭터 코드 재사용 금지. 공개 사용 권리는 최종 공개 전 사용자 확인 필요.

## 확정된 내용 순서

1. 질문: 웨캔기어를 아는가 → 웨이브 캔슬 기상 어퍼의 줄임말 → 실제 동작.
2. 역사 설명을 시작하는 척: 철권 태그 시절로 되감기 → 오늘은 다루지 않음 → 빨리감기로 현재 복귀. 역사 진술은 아직 검증 전.
3. 오늘은 자세한 사용 방법과 실전 유용성. 발동 조건에 대한 과장된 자신감 → '아는 것과 손으로 하는 건 별개' → 커맨드로 진입. 여기서 실험 근거를 미리 꺼내지 않음.
4. 기본 커맨드 시각화 → '설명만 들으면 간단해 보입니다.' → '직접 해보기 전까지는요.'
5. 풍신권 / 선 자세 기술 두 실패 → 타이밍이 어긋나면 실패 → 설명을 찾아본 과정.
6. 모호했던 정보들을 요약 → 직접 프레임별 테스트했다는 동기. 실패 영상 1 → 2 → 4 → 8 → 16 확대 몽타주.
7. '그렇다면, 정확히 언제 눌러야 할까요?' → ↘부터 뒤 / 뒤부터 RP 기준 설명.
8. 뒤 입력은 7·8·9f. RP 허용폭 설명은 반드시 7 → 8 → 9 순서(각각 1 / 1–2 / 1–3f).
9. 해당 타이밍에 맞추면 된다고 정리. 8+1을 추천하는 별도 연습 파트는 삭제.
10. 실전에서 유용한 선택지 → 굳이 어려운 캔슬이 필요한가? → 단순 ↓ / ↓↙← / ↙의 세 대안 비교.
11. 웨이브 캔슬을 기준 행에 둔 총 4행 비교표 → 압도적인 시간상 효율은 아니라는 사용자 결론 → 아직 어렵다면 쉬운 대안을 제안.

## 시각 원칙

- A 플레이를 크게 먼저 보여주고 비교 위치로 축소·이동. B도 크게 보여준 후 축소·이동. 처음부터 작은 두 화면을 장시간 고정하지 않는다.
- 확대된 입력 기록에서 그래픽으로 자연스럽게 이어지게 설계. 근거 없는 오래 멈춘 화면, 의미 없는 장식 모션, 매번 독립된 제목 슬라이드 금지.
- 입력은 칸 안에 표시. 선행 커맨드와 이후 프레임을 하나의 흐름으로 연결. 위의 6N23과 아래 별도 표처럼 반복 분리 금지.
- 방향 표기는 → ★ ↓ ↘ ← ↙로 통일. ★ = 중립. 방향 숫자 6/2/3/4/1이나 N을 기본 화면 표기로 쓰지 않는다. 214를 말로 소개할 수 있지만 화면 입력은 ↓ ↙ ←. RP와 프레임 숫자는 유지.
- 선행 → ★ ↓는 순서만 알려주며 각 1f라고 꾸미지 않는다. ↘의 0은 설명용 상대 기준. 실제 첫 프레임 포함 규칙은 확인할 것.
- 7·8·9 구간을 먼저, RP 허용 칸을 나중에 강조. 한꺼번에 모든 정보 표시 금지.
- 실패 16분할은 서로 다른 실제 시도만 사용할 때 실험 증거로 취급. 더미/복제는 검토용 표시를 붙여야 하며 최종에서 실제 반복 테스트로 위장 금지.
- 지속적인 가제, 페이지 번호, 템플릿형 상단 바 금지. '사라진 기상어퍼', '입력을 칸 안으로' 문구는 쓰지 않는다.
- 표는 비교 결과가 필요해지는 후반에만. 수치가 없는 항목은 미측정 표시, 막대 길이도 임의 수치로 만들지 않음.

## 주장 / 불확실성

- 독립 테스트 후 선행 자료를 알게 됐음. 최초 발견/유일한 정답/커뮤니티 전체에 정보가 없었다는 주장 금지.
- 자신감 대사는 의도적인 수사이지 지식 우위가 검증된 사실이 아니다. '정확한 발동 조건' 범위로 한정하고 유일성 주장으로 강화하지 않는다.
- 실전 유용성과 어려운 입력의 비용 대비 이점은 별도 질문. 시간만 비슷하다고 거리·접근·선택지·위험이 모두 같다고 일반화하지 않는다.
- 공개 영상/내레이션/자막/설명란에 내부 참고 링크 자동 삽입 금지. 타인의 영상·댓글을 직접 재사용하려면 별도로 권리/표기 방식을 확인하며 내부 보관 지시를 무단 복제 허가로 해석하지 않는다.
