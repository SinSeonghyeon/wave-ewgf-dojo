# 미시마 도장 AI 문서

`AGENTS.md`(루트)는 모든 세션의 공통 규칙과 문서 라우팅만 관리합니다. 이 폴더의 문서는 해당 작업에서만 필요한 사실의 정본입니다.

## 문서 목록

- `PLAN.md`: 수익화·기능 로드맵, 체크박스 진행 상태, 날짜별 진행 로그. 다음 작업은 여기서 고른다.
- `CODE_MAP.md`: `index.html` 안의 코드 구조(입력 레이어, 크라우치 대시 상태 머신, 초풍 판정, i18n, 기록 저장 형식, 차트, 스테이지), 판정 상수, 검증 절차.
- `reviews/`: 날짜별 코드 리뷰 결과와 수정 내역.

## 관리 원칙

- 구현과 유지보수에 영향을 주는 사실만 남긴다.
- 같은 규칙을 여러 파일에 반복하지 않는다. 충돌하면 규칙·안전·라우팅은 `AGENTS.md`, 주제별 사실은 해당 문서를 우선한다.
- 세션 임시 메모는 여기가 아니라 `.sandbox/`(gitignore)에 둔다.
