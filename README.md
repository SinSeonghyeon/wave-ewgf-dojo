# 미시마 도장 (Mishima Dojo / 三島道場)

철권 미시마류 커맨드(웨이브 대시, 초풍) 입력을 브라우저에서 프레임 단위로 판정하고, 코치 피드백과 기록을 남기는 연습 도구.
비공식 팬 제작. 파일 하나(`index.html`)로 동작하며 빌드나 의존 파일이 없다. UI는 한국어·영어·일본어(헤더 토글, 브라우저 언어로 자동 선택).

- 바로 쓰기: https://mishimaryu.com/ (예전 주소 https://sinseonghyeon.github.io/wave-ewgf-dojo/ 는 여기로 넘어온다)

| 온라인 | 첫 방문에 닉네임 지정(중복 불가, 브라우저에 저장) · 순위(초기화 없이 누적, 닉네임당 최고 1건, 상위 10명 + 내 순위/상위 %, 측정 모드가 끝나면 자동 등록) · 측정 결과 창(상위 %별 등급 SS·S·A·B·C·D와 측정 모드별 코멘트, 공유 카드) · 오늘·누적 방문자 수 · 한마디 게시판(글마다 좋아요/싫어요, 닉네임당 글 하나에 표 1개, 취소·변경 가능) |

## 조작 (기본값)

- 방향: WASD 또는 방향키. 1P 기준 → 가 앞(6).
- 버튼: U=1(LP), I=2(RP), J=3(LK), K=4(RK).
- 게임패드: 십자키·왼쪽 스틱, □/X=1, △/Y=2, ✕/A=3, ○/B=4 (표준 매핑 인덱스 2,3,0,1). 판정 시각은 패드 기기의 갱신 시각(`gamepad.timestamp`)이며, 브라우저가 패드를 읽는 주기가 느리면 그만큼의 오차가 남는다.
- 터치(폰·태블릿): 화면 아래에 원형 방향 패드(엄지를 굴려 f→N→d→df)와 1 2 / 3 4 버튼이 나타난다. 설정에서 자동/켜기/끄기.
- 웨이브 표기: `6N23 6 N 6N23 6 N …`. 3 직후의 6은 후딜레이 캔슬, 다음 대시는 별도의 시작 6이 필요하다(그 시작 6은 대시로도 인정).
- 기술: 초풍 6N23+2(오른손) · 통발 66+2(오른손, 중단) · 나락 6N23+4(오른발, 하단, 저스트 없음).
- 소리: 헤더 스피커 아이콘이나 설정 창의 배경음 토글로 배경음만 끌 수 있다(효과음 유지). 설정은 새로고침 후에도 유지되며, 배경음을 켜면 전체 소리도 함께 켜진다. 설정 창에서 전체 소리와 배경음·효과음 볼륨을 따로 조절할 수 있다.
- 옷장: 스테이지 오른쪽 위 톱니 아래 옷 버튼. 잠긴 칩에 마우스를 올리면 필요한 업적이 보인다.
- 보상 수령: 옷 버튼 아래 보물상자. 업적·출석 보상이 생기면 작은 알림이 상자로 날아가고 개수 배지가 켜진다. 상자를 누르면 쌓인 보상을 모두 받고 기존 획득 연출이 나온다. 받기 전에는 착용할 수 없으며 새로고침해도 보상이 남는다. 측정·카운트다운·결과 연출·대화상자 중에는 수령할 수 없다.
- 백대시: `4 N 4`로 백대시, 4를 잡은 채 약 10f 뒤에 `1(↙)`로 경직을 끊고 1에서 4로 바로 굴려 다음 `4 N 4` — 표기 `414 N 414 N …`. 1로 앉는 이유: 중립 뒤 2/8은 횡이라 가드가 풀린다(그렇게 끊으면 실수로 표시). 캔슬 없이 끝내면 약 26f 동안 경직(뒤로만 못 감: 백대시·뒤 걷기 없음, 앉기나 횡으로 풀림)이라 다음 백대시가 나가지 않는다. 이 경직은 어느 모드에서나 스테이지에 적용된다. 자유 연습에서는 첫 1 캔슬부터 판정 문구가 나오고, 백대시 10초는 10초 동안 물러난 거리(m)로 겨룬다(등급: 매우 빠름·빠름·보통·느림 = 세트 속도 m/s).
- 더미 격파 30초: 상단·중단·하단 더미가 무작위로 나온다. 상단=초풍, 중단=통발, 하단=나락으로 맞으면 5점(저스트를 놓친 풍신권은 상단 2점), 크라우치 대시는 연속 수만큼 최대 3점. 틀린 기술은 헛침.

## 웨캔기어 연습

모든 모드에서 같은 커맨드로 기술을 사용할 수 있다. 자유 연습에서도 웨캔기어가 나오며, 웨캔기어 모드에서도 초풍·나락·통발 등을 사용할 수 있다. 뒤 입력 없이 RP를 누르면 기존 초풍 판정으로 이어진다. 다른 기술은 웨캔기어 도전 횟수에 포함하지 않는다.

상단 **웨캔기어 연습**에서 전체 커맨드를 입력한다. 단계 선택 없이 오른쪽 평가 패널에 A(뒤 입력)·B(RP 연결)가 함께 나온다. 모바일에서는 평가 패널이 아래에 배치된다.

- 하단에 기존 입력·프레임 이력을 표시한다. 대각 입력부터 현재 프레임 칸과 A 숫자가 실시간으로 진행하고, 뒤 입력 후에는 A를 고정해 보여주며 B가 0f부터 진행한다. 모바일은 진행 칸을 따라 스크롤하며 15f 이후에도 숫자는 계속 증가한다. 입력 완료·취소 시 진행 표시가 멈춘다.
- 선행 웨이브는 `6N23` 한 덩어리로 표시하고 프레임 표는 마지막 대각을 1f로 시작한다. 그 이전 입력 시간은 평가하지 않는다. 선행 N을 생략한 `623`도 허용한다.
- 뒤 8f이면 RP 1f, 뒤 9f이면 RP 1~2f, 뒤 10f이면 RP 1~3f가 성공이다. A는 대각 입력 순간을 1f로 세므로 실제 경과 7·8·9f에 해당한다. A는 60Hz 경과 반올림 +1, B는 뒤 입력 순간을 0f로 두고 경과만 반올림한다. 상세의 경과 소수 f·ms는 포함 프레임을 더하지 않은 실제 시간이다.
- 대각~뒤 사이는 중립과 앞 입력 1회, 뒤~RP 사이는 뒤 유지·중립을 허용한다. 뒤+RP 동시는 실패다. 다음 완전한 웨이브의 마지막 대각으로 기준을 갱신하며 캔슬 앞과 시작 앞은 별도로 필요하다.
- **10회 도전 시작** → 3초 카운트다운 → 랜덤 과제 10개. `웨이브 N회 후 웨캔기어`에서 N은 0~3, 정확히 N+1번째 웨이브에서 성공해야 한다(0이면 첫 번째, 2이면 세 번째). 오른쪽에 현재 횟수와 과제를 표시한다. 웨캔기어 RP 평가 후 성공·실패 모두 다음 과제로 넘어가며, 선행 오류와 1초 중단은 횟수·성공률에서 제외하고 같은 과제를 다시 한다. 완료 시 성공률·최고 연속 표시. 도전 취소/모드·방향·설정·포커스 전환으로 취소할 수 있고 도전 후 자유롭게 연습을 계속할 수 있다.
- 성공하면 자체 캐릭터가 기상어퍼를 하고, 사거리 안의 더미가 반응한다. 기상어퍼 효과음이 나오며, 통발·나락에도 각각의 효과음이 있다. 백대시도 실제로 발동할 때 전용 효과음이 나온다(뒤 걷기·경직 중 무효 입력에는 없음). 더미에 명중하면 피격음과 짧은 충격 원·불꽃이 나온다. 헛침에는 피격음이 없고, 연출 끄기·동작 줄이기는 시각 효과만 생략한다. 소리는 전체 소리·효과음 볼륨 설정을 따른다.
- 세션·도전 기록은 새로고침하면 사라진다. 기존 초풍·웨이브·백대시 통계·업적·측정 점수·순위·공유에는 섞이지 않으며, 이 모드에서 사용하는 다른 기술도 기존 누적 통계에는 기록하지 않는다. 다른 모드에서 웨캔기어에 앞서 쓴 웨이브는 기존 규칙대로 집계한다. 이 모드의 초기화도 WSC 기록만 지운다.

초풍은 웨캔기어와 달리 **각 입력 시각을 공통 60Hz 칸에 반올림한 뒤 같은 칸인지** 비교한다. 0.5/0.7/0.9f 선택은 제거했다. 이전 순위·최고 기록은 유지되므로 과거 판정으로 얻은 기록과 함께 존재한다. 사범 피부 업적의 기존 획득·진행은 유지하고, 새 진행은 동일 프레임 성공 중 입력 간격 ±8ms 이내를 센다.

## 알려진 한계

- 초풍의 공통 프레임 칸은 페이지 시간 원점을 기준으로 하며 게임 프레임과 동기화되지 않는다. 웨캔기어 역시 사용자 실험에 기반한 연습용 근사다.
- 브라우저 입력 해상도(약 4ms)와 키보드 폴링 때문에 실제 게임 판정과 오차가 있다. 페이지에도 명시.
- 백대시의 이동 구간(10f)·경직(26f)·최소 홀드(6f)는 실측이 아니라 체감 기반 근사값이다. 거리(m)는 이 모델로 계산한 값이며 게임 안 거리와 다르다.
- 터치 입력은 샘플링이 8~16ms라 키보드보다 판정 정밀도가 낮다. 빠른지 늦은지 경향을 보는 용도로 쓰고, 순위는 키보드·패드와 같은 보드에 올라간다.
